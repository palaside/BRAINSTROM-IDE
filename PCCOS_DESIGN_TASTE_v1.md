# PCCOS_DESIGN_TOKENS_v1

## Base Preset

Vega

## Accent

Purple

## Design Direction

Startup sharpness + Developer command center

## Identity

- Information First
- Tool First
- Dense but Readable
- Functional Beauty
- Fast
- Sharp
- Professional

## Typography

Primary:
Inter

Code / Technical:
JetBrains Mono

## Color Mood

- Dark-first
- Purple accent
- Neutral background
- High contrast for system status
- Green for running
- Yellow for warning
- Red for critical
- Blue for waiting/info

## Component Style

- Compact cards
- Clear borders
- Minimal shadow
- Sharp spacing
- No excessive decoration
- No random gradients
- No glassmorphism unless useful

## PCCOS UI Priority

1. Runtime clarity
2. Agent status
3. Skill / Pack visibility
4. Mission progress
5. Verification state

## Avoid

- Card overload
- Decorative hero sections
- Big marketing layout
- Random animations
- Unreadable dark mode
- UI that looks like AI template
