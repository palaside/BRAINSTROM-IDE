# Architecture


## Architecture Profiles

### Website Profile
ใช้เมื่อเป็น landing page / portfolio / content website

### Web App Profile
ใช้เมื่อมี backend, database, auth, dashboard หรือ workflow หลายหน้า

### SPA Profile
ใช้เมื่อเป็น browser tool หน้าเดียว มี state/interaction สูง

### Electron Profile
ใช้เมื่อเป็น desktop app / .exe / local filesystem

### Python CLI Profile
ใช้เมื่อเป็น command line tool / automation / local script

### Documentation System Profile
ใช้เมื่อเป็นระบบเอกสาร / knowledge architecture / policy docs
