# PCCOS Design Constitution v1

## Identity

PCCOS is not:

* SaaS Dashboard
* Startup Landing Page
* Generic AI Assistant
* Analytics Admin Panel

PCCOS is:

Military Intelligence Operating System
+
Civilization Runtime
+
Command Center

---

## Design Principles

1. Command First

Every screen must answer:

* What is happening?
* What requires attention?
* What is the next action?

2. Hierarchy Before Decoration

Information hierarchy is more important than visual effects.

3. Strategic Clarity

The user must understand system state within 3 seconds.

4. Operational Focus

Avoid decorative widgets.

Every panel must serve an operational purpose.

5. Civilization Thinking

The interface represents an evolving civilization.

Brain
Soul
Body
Skills
Knowledge
Runtime
Mission

are first-class entities.

---

## Visual Direction

Primary Mood:

Military Intelligence
+
Civilization OS

Secondary Mood:

Premium
Focused
Technical

Avoid:

* Excessive glassmorphism
* Neon cyberpunk overload
* Marketing gradients
* Card spam

Prefer:

* Deep dark surfaces
* Sparse accent usage
* Strong hierarchy
* Mission-oriented layouts

---

## Commander View

The Commander is always visible.

Commander Profile is a permanent element of PCCOS.

---

## Runtime Rule

Runtime state must be visible globally.

Brain
Soul
Body
Secrets

must always expose status.

---

## Verification Rule

Every screen must answer:

Why does this exist?

If no operational purpose exists, remove it.
